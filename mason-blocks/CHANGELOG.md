# Mason Blocks - Changelog

All notable changes to the Mason Blocks plugin will be documented in this file.

## [1.0.0] - 2024-12-17

### Added
- Initial release of Mason Blocks plugin
- Hero Section block for product headlines and imagery
- Feature Grid block for 2-3 column feature highlights
- Product Spotlight block for WooCommerce product focus
- Sticky Buy Bar block for floating add-to-cart functionality
- Specs Table block for technical specifications
- Section Divider block for visual separation
- Product Card block (PHP render) for server-side rendering
- Product Card block (React) for interactive product display
- Complete WooCommerce integration with Blocks API
- Apple-inspired design system
- WCAG 2.1 AA accessible markup
- Performance optimizations for 95+ Lighthouse scores
- Block registration system with Mason category
- Dedicated blocks.css stylesheet
- Full documentation and examples

### Features
- 8 custom blocks total (7 PHP, 1 React)
- Server-side rendering for optimal performance
- Semantic HTML5 with ARIA labels
- Responsive design for all devices
- Independent plugin activation
- Theme-agnostic (works best with Mason theme)
- Zero vendor lock-in
- Build system with @wordpress/scripts

### Technical
- WordPress 6.4+ compatibility
- PHP 8.0+ requirement
- WooCommerce 8.0+ integration
- Block API version 3
- Schema.org markup for products
- Lazy loading support
- RTL language support ready
